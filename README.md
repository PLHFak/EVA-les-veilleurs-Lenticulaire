# Les Veilleurs, vitrine lenticulaire : note de calcul

Site statique présentant la note de calcul thermique, hygrométrique et UV de la vitrine lenticulaire de 2 × 1,8 m posée sur la digue de Lombardsijde.

- `index.html`, `assets/` : le site (aucune étape de build, polices et rendu des formules embarqués).
- `calcul/` : les scripts Python dont viennent les chiffres.

Pour le voir en local : `python3 -m http.server` puis ouvrir http://localhost:8000.
